## Bug 概览

| 严重程度 | 数量 | 核心问题 |
|----------|------|----------|
| 高 | 2 | 下单表单校验缺失、信用卡号无格式校验 |
| 中 | 2 | 日期字段无校验、卡号无长度限制 |
| 低 | 3 | 登录超长输入无反馈、购物车删除刷新、未登录权限不明确 |

**核心发现：下单模块输入校验严重缺失。**

## 测试方法论

- **等价类划分** — 有效 / 无效输入分类
- **边界值分析** — 空值、单字符、超长字符串
- **异常场景优先** — 每个模块重点覆盖非法输入和极端情况
- **优先级分级** — 高/中/低三级，高风险模块优先测试
