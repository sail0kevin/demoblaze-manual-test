# Demoblaze 功能分析

> 测试对象：https://demoblaze.com
> 分析日期：2026-05-15

---

## 1. 用户模块

| 功能 | 说明 |
|------|------|
| 注册（Sign up） | 新用户创建账号，输入用户名+密码即可注册 |
| 登录（Log in） | 已有账号登录，登录后显示用户名 |
| 登出（Log out） | 登录后出现，点击退出当前账号 |

## 2. 商品模块

| 功能 | 说明 |
|------|------|
| 商品列表 | 首页以卡片形式展示商品，包含图片、名称、价格、描述 |
| 分类筛选 | 左侧分类栏：Phones / Laptops / Monitors，点击筛选对应商品 |
| 商品详情 | 点击商品卡片进入详情页，展示大图、名称、价格、描述 |
| 分页浏览 | 底部分页按钮 Previous / Next，切换商品列表页 |

## 3. 购物车模块

| 功能 | 说明 |
|------|------|
| 添加商品 | 从商品详情页点击 Add to cart 加入购物车 |
| 查看购物车 | 点击顶部 Cart 进入购物车页面 |
| 删除商品 | 购物车中可删除已添加的商品 |
| 下单结算 | 购物车中点击 Place Order 进入下单流程 |

## 4. 下单模块

| 功能 | 说明 |
|------|------|
| 填写订单 | 弹出表单：姓名、国家、城市、信用卡号、月、年 |
| 提交订单 | 点击 Purchase 提交 |
| 订单确认 | 提交后显示确认信息：购买成功 + 订单金额 |

## 5. 其他页面

| 功能 | 说明 |
|------|------|
| 首页（Home） | 展示所有商品 |
| 联系我们（Contact） | 联系表单页面 |
| 关于我们（About us） | 网站介绍 |
| 底部信息 | PRODUCT STORE 版权信息等 |
